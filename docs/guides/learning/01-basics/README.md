# 01 Basics

The general knowledge you need to read this repository, always taught with examples from it. Four
folders; read them in the order that matches your gaps.

| Folder | Read it when | Lessons |
|---|---|---|
| [python/](python/README.md) | You cannot yet read a `.py` file | 7: values, conditions and loops, functions and errors, classes, modules and types, iterators and concurrency, reading a real function |
| [tools/](tools/README.md) | You want to run or check anything | 7: the terminal, uv, pytest, ruff and mypy, git and pull requests, CI, the JavaScript and Rust tools |
| [recognition-ideas/](recognition-ideas/README.md) | You want to know what "recognition" means | 6: vectors, models and ONNX, the face pipeline, kinds of recognition, thresholds and errors, nearest-neighbour search |
| [topic-map/](topic-map/README.md) | You want the wider field | 2: the old research checklist, every topic with what the project did about it |

None of these lessons assumes the earlier ones in *another* folder, except that the Python lessons
help with everything that follows. Back to the [guide index](../README.md).
