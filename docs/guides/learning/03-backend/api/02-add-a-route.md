# API 02 Add a route

## 1. What this is and why it exists

Adding a route is the most common backend change, and it touches more than one file on purpose: the route, its
registration, a test, and the generated contract the front end is typed from. This lesson walks through a
complete, tiny route end to end, exactly as it was done in a **scratch checkout on 2026-10-12** (everything was
discarded afterwards: this guide's pull request commits no route), including what fails if you skip a step.

> **First, the rules.** `.agents/rules/scope.md` forbids inventing API contracts the specs do not define, and
> specs are not edited without the owner's approval. A real new route needs: the requirement, an entry in
> `docs/specs/API and Contracts.md` (agreed with the owner), and a plan or implementation entry. The route below is
> a **practice route** to learn the mechanics, never to be merged.

## 2. Where it lives

| Step | File |
|---|---|
| The route | `backend/api/routes/<topic>.py` |
| Registration | `backend/api/routes/__init__.py` |
| Shared dependencies | `Library`, `get_backend` in `backend/api/dependencies.py`; `PageQuery` in `pagination.py`; `ApiError` in `errors.py` |
| The logic | a use case or repository in `backend/app/...` (routes stay thin) |
| The test | `tests/integration/test_api_<topic>.py` using the `api` / `processing_api` fixtures |
| The contract | `frontend/src/api/openapi.json` and `schema.d.ts`, regenerated by `npm run generate:api` |
| The spec | `docs/specs/API and Contracts.md` |

## 3. How it works

A route is a Python function with a decorator. FastAPI turns the type hints into validation and into the
OpenAPI document:

```python
router = APIRouter(tags=["library"])

class LibraryStats(BaseModel):          # the answer shape: becomes a TypeScript type
    sources: int
    identities: int

@router.get("/library/stats")           # becomes GET /api/v1/library/stats
def library_stats(library: Library) -> LibraryStats:     # `Library` = "the open library, or 503"
    def read(session): ...
    return library.unit_of_work.read(read)
```

Conventions to follow (from [the API README](README.md)): plain `def`; take `Library`; read with
`unit_of_work.read`, write with `unit_of_work.write(lambda session: ...)`; raise `ApiError(status, "CODE", "message",
details=...)` for expected failures; return an API schema; announce an event after a write
(`backend.announce(...)`); collections use `PageQuery` and `paginate`. The function name becomes the OpenAPI
`operationId` (`generate_unique_id_function=operation_id` in `app.py`), and a test checks that ids are unique.

## 4. Try it

**Works with no models. Verified 2026-10-12 in a scratch change that was then fully discarded** (`git status`
clean afterwards). Do it in a branch you will throw away.

1. **Write the route**, `backend/api/routes/library_stats.py`:

   ```python
   """A practice route: how many sources and active identities the library holds."""

   from fastapi import APIRouter
   from pydantic import BaseModel
   from sqlalchemy import func, select
   from sqlalchemy.orm import Session

   from backend.api.dependencies import Library
   from backend.app.identities.models import Identity, IdentityState
   from backend.app.sources.models import Source, SourceState

   router = APIRouter(tags=["library"])


   class LibraryStats(BaseModel):
       sources: int
       identities: int


   @router.get("/library/stats")
   def library_stats(library: Library) -> LibraryStats:
       def read(session: Session) -> LibraryStats:
           sources = session.scalar(
               select(func.count()).select_from(Source).where(Source.state == SourceState.ACTIVE)
           )
           identities = session.scalar(
               select(func.count()).select_from(Identity).where(Identity.state == IdentityState.ACTIVE)
           )
           return LibraryStats(sources=sources or 0, identities=identities or 0)

       return library.unit_of_work.read(read)
   ```

2. **Register it** in `backend/api/routes/__init__.py`: add `library_stats,` to the import list (alphabetical) and
   `api_router.include_router(library_stats.router)` next to the others.
3. **Write its test**, `tests/integration/test_api_library_stats.py`:

   ```python
   from tests.fixtures.api import Api, imported


   async def test_the_counts_follow_the_imports(api: Api) -> None:
       empty = (await api.client.get("/api/v1/library/stats")).json()
       assert empty == {"sources": 0, "identities": 0}

       await imported(api, path=str(api.image("a.png")))

       assert (await api.client.get("/api/v1/library/stats")).json() == {"sources": 1, "identities": 0}


   async def test_the_route_needs_the_token(api: Api) -> None:
       response = await api.client.get("/api/v1/library/stats", headers={"Authorization": "Bearer x"})
       assert response.status_code == 401
   ```

   Run it: `uv run pytest tests/integration/test_api_library_stats.py -q`. Expected (observed): `2 passed`.
4. **Run the contract test:** `uv run pytest tests/contracts/test_openapi_contract.py -q`. Expected (observed):
   **it fails** with `frontend/src/api/openapi.json is stale: run npm run generate:api and commit the result`. The
   document is built from the real app, so it noticed the new route.
5. **Regenerate the contract:** `npm run generate:api`. It runs `uv run python -m backend.api.openapi` (rewrites
   `frontend/src/api/openapi.json`, prints `wrote frontend/src/api/openapi.json`) and then
   `openapi-typescript` (rewrites `frontend/src/api/schema.d.ts`). Observed: `git diff --stat` showed
   `openapi.json | 49 +` and `schema.d.ts | 53 +`, and `schema.d.ts` now contains `LibraryStats` and
   `library_stats: { ... }`. Re-run step 4: `6 passed`.
6. **Run the repository's checks:** `uv run ruff format --check .`, `uv run ruff check .`, `uv run mypy`,
   `npm run typecheck`. Observed: on the first draft, `ruff check` failed `E501 Line too long (102 > 100)` on the
   one-line docstring; after shortening it everything was clean (`mypy`: `Success: no issues found in 293 source
   files`; `tsc -b` printed nothing).
7. **Call it for real** (backend running, library open): `curl -s -H "$H" $B/api/v1/library/stats`. Expected: the counts of your library as JSON, for
   the lesson-07 run `{"sources":3,"identities":2}` (not run against a live library in the dry run; the test in step 3
   covers the same query).
8. **Throw the practice away:** `git restore` the three edited files, delete the two new ones. The commit-ready
   version of a real route also needs: the spec entry, the front-end use, an implementation entry in
   `docs/implementations/`, and `PROJECT_STATUS.md`/`CONTEXT.md` if what is built changes.

## 5. Change it

Change an *existing* route safely by working outward from its test. Each of these one-line mutations was run on
2026-10-12 against the named test file and made it fail, which is the point: the tests pin the contract.

| Mutation (then `git restore` the file) | Test file | It failed |
|---|---|---|
| `NOT_PROCESSED = "NOT_PROCESSED"` to `"UNPROCESSED"` in `sources.py` | `tests/integration/test_api_sources.py` | `test_a_managed_import_copies_the_image_into_the_library` |
| `status_code=202` to `200` on `process_source` | `tests/integration/test_api_processing_routes.py` | `test_processing_a_source_is_accepted_tracked_and_completed` |
| `status_code=202` to `200` on `cancel_job` | `tests/integration/test_api_jobs.py` | `test_a_queued_run_is_cancelled_through_its_job` |

If the change alters a response shape, run `npm run generate:api` and look at the `schema.d.ts` diff: that is the
list of front-end places the compiler will now check (`npm run typecheck`).

## 6. Break it on purpose

Skip a step and read the failure:

- **Forget to register** the router: the route simply does not exist (`404 NOT_FOUND`), and the test you wrote
  fails with `404`.
- **Forget `npm run generate:api`:** `test_the_committed_document_is_what_the_application_produces` fails; in CI the
  Frontend job fails at "Generated API types are up to date".
- **Return a database row** instead of a schema, or forget the return annotation: FastAPI cannot build the
  response model and the types in `schema.d.ts` lose the shape. Always annotate the return type.
- **Take a session directly** or commit inside the route: the unit of work owns transactions; see
  [transactions](../../02-data-and-storage/03-transactions-and-unit-of-work.md).

## 7. Exercises

1. Which two generated files change when you add a route?
2. Why must the route's return type be an API schema and not a database model?
3. A route changes data. Which call do you wrap the change in, and what do you do after it commits?
4. Why do route functions use `def` and not `async def`?
5. Which test tells you the contract file is stale?

**Answers**

1. `frontend/src/api/openapi.json` and `frontend/src/api/schema.d.ts`.
2. The schema is the public contract (and the TypeScript type); a model leaks internals such as paths and
   changes whenever the table does.
3. `library.unit_of_work.write(...)`; then `backend.announce(...)` the event.
4. FastAPI runs a plain `def` in a worker thread, so blocking database and file work does not freeze the event loop.
5. `tests/contracts/test_openapi_contract.py::test_the_committed_document_is_what_the_application_produces`.
