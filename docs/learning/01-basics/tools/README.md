# The tools around the code

Code is only half a project. The other half is the machinery that installs it, runs it, checks it and
keeps its history. Each lesson here explains one tool and the exact commands you will type.

| # | Lesson | Tool | You will be able to |
|---|---|---|---|
| 01 | [Terminal and environment variables](01-terminal-and-environment.md) | shell, env vars | type commands, set `FACEIDENTIFY_*` settings, read output |
| 02 | [uv and dependencies](02-uv-and-dependencies.md) | `uv`, `pyproject.toml`, `uv.lock` | install, run, and see which packages the project uses |
| 03 | [pytest](03-pytest.md) | `pytest` | run the whole suite, one file, one test, with coverage; read a test |
| 04 | [ruff and mypy](04-ruff-and-mypy.md) | `ruff`, `mypy` | run the style and type checks and fix what they report |
| 05 | [Git and pull requests](05-git-and-pull-requests.md) | `git`, hooks, `gh` | follow this project's branch, commit and PR workflow |
| 06 | [CI](06-ci.md) | GitHub Actions | know what each required check does and reproduce it locally |
| 07 | [JavaScript and Rust tools](07-javascript-and-rust-tools.md) | `npm`, Vite, Vitest, oxlint, `cargo` | run the front end and shell checks |
