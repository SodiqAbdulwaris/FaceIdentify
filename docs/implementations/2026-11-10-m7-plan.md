# M7 plan: live cameras

- **Date:** 2026-11-10
- **Milestone / tracker IDs:** M7 (TST-071 to TST-077), SEC-005, SEC-006
- **Status:** done; documentation only (no code, dependency or spec changed)
- **Commits:** PR (this one): `docs: add the M7 camera plan`

## What changed

`docs/plans/M7_PLAN.md`: where things stand, the scope the specs ask for, constraints, seven steps sized as
small PRs, the proposed API surface, dependencies, definition of done, risks, and decisions C1 to C12.
`.agents/CONTEXT.md`, `docs/plans/PROJECT_STATUS.md` and `docs/plans/PROGRESS.md` point to it.

## Why

The owner's delegation of 2026-11-09 ("i'll leave the rest of the decisions entirely to you"; scope through M8)
requires a plan in `docs/plans/` before any M7 code.

## Decisions

All are delegated decisions of the agent, reversible by the owner, with reasoning in plan section 8: capture
through the pinned LGPL ffmpeg with DirectShow over a pipe (C1); 5 frames per second, a buffer of one, one
session, local devices only (C2); persist per closed encounter, at most three face crops, no frames (C3); nothing
starts by itself and a "Camera on" indicator (C4); a camera never creates an identity (C5); a `live` class in the
worker lease (C6); reconnect timeout 30 s (C7); encounter gap 5 s (C8); permanent deletion through the M5 erasure
path (C9); camera face search in scope (C10); how the hardware rows are scoped (C11); testing without a camera
(C12). The plan depends on the FFmpeg recommendation of PR #233, which is pending confirmation.

## Verification

Documentation only. Facts about the code and specs were read from the repository on 2026-11-09 and 2026-11-10:
`SourceKind` has `IMAGE` and `VIDEO` only, `JobType` has no camera type, revision 0001 has no camera tables,
`backend/app/cameras/` is empty, the API spec names `cameras` and `camera.*` without routes, and the lease has
two classes. The DirectShow device in the pinned build was run in the D2 record. Not verified: Windows camera
privacy behaviour, DirectShow device naming on this machine, any throughput figure for live frames.
