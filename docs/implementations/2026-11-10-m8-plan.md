## Decisions

All are delegated decisions of the agent, reversible by the owner, with reasoning in plan section 8: a per-user
NSIS installer (R1); one offline installer instead of the online bootstrapper of `tech-stack.md` section 12 (R2);
PyInstaller onedir as Tauri resources (R3); the shipped `onnxruntime-windowsml` build with telemetry off (R4); the
D2 FFmpeg recommendation packaged (R5, contingent on its confirmation); weights never bundled or downloaded, hash
checked from a user-supplied folder (R6); no policy file shipped, never overwritten, the automatic point only by the
user's own choice (R7); the default library folder moves to `Documents\FaceIdentify` (R8); in-place upgrade with a
pre-migration backup and no updater (R9); unsigned, with the consequences stated (R10); TST-083 scoped to one
component, fail closed (R11); CI proves the installer on the development profile and the owner's machine proves the
real models (R12).
