## `SourcePage.test.tsx`: "leaves the page ... deleted for good"

Reproduced locally (5 of 6 runs failed under machine load, `expected <img alt="beach.png"> to be
null`). Cause: the test waited for `router.state.location.pathname` to be `/library` and then asserted
at once that the image was gone, but the router state changes before React commits the new page, so
the old page could still be mounted. A test race, not a component bug. Fix: the removal is awaited with
`waitFor`; it still asserts that the image is gone. After the fix: 8 of 8 runs of the file pass, then
`npm test` (206 tests), `npm run typecheck`, `npx oxlint --deny-warnings` and `npm run build`.
